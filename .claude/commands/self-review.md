Tự duyệt thay đổi hiện tại (git diff) trước khi mở pull request.

1. Đối chiếu với từng ý trong checklist ở .github/pull_request_template.md.
   Với mỗi ý: ĐẠT / KHÔNG ĐẠT / KHÔNG ÁP DỤNG, kèm file và dòng code làm bằng chứng.
2. Kiểm tra mọi tên bảng, cột, endpoint, mã lỗi, sự kiện trong diff đều có trong docs/.
   Liệt kê tên nào không tìm thấy.
3. Viết mô tả pull request theo đúng mẫu .github/pull_request_template.md.
Không tự sửa code ở bước này; chỉ báo cáo. Ý nào KHÔNG ĐẠT thì đề xuất cách sửa.
